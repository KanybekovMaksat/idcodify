# ID-карта студента Codify

Страница, которая открывается с NFC-карты студента: ФИО, архетип личности, радар навыков с ростом после диагностики, пройденные курсы с превью сертификатов.

Карта хранит только ссылку вида `https://<домен>/?card=000417`. Данные живут на сервере.

## Запуск

```
npm install
npm run dev
```

Открыть http://localhost:5174/?card=000417

Предпросмотр статуса карты: добавить `&status=diagnostic`, `&status=locked` или `&status=active`. Переключатель над шапкой делает то же.

Другие команды: `npm run build` (сборка в `dist/`), `npm run typecheck`.

## Как устроено

- `index.html` — страница.
- `src/main.ts` — отрисовка: переключатель статуса, шапка, архетип, навыки, курсы, сертификаты, проекты. Тема светлая; тёмная включается параметром `?theme=dark`.
- `src/data.ts` — тип профиля и загрузка. Пока нет API, для любого номера карты возвращается тестовый студент. Проекты, добавленные на устройстве, хранятся в localStorage; картинка превью уменьшается до 800 px и лежит там же как data URL.
- `src/archetypeCard.ts` — описания 12 архетипов от третьего лица, с подстановкой имени и рода.
- `src/radar.ts`, `src/icons.ts` — радар навыков и значки, копия из проекта диагностики.
- `src/profile.css` — стили только на токенах дизайн-системы.
- `src/tokens.css` — токены дизайн-системы, сгенерированный файл, не править.
- `src/fonts.css`, `public/fonts/` — Inter Variable, латиница и кириллица.
- `public/projects/` — обложки проектов из примера.

## Статусы карты

- `diagnostic` — карту выдали после диагностики. Видны архетип и навыки первого замера, сверху срок действия и кнопка «Записаться на курс».
- `locked` — срок вышел, на курс не записались. Остаются имя и кнопка записи, остальное скрыто.
- `active` — студент. Полный профиль: рост навыков, курсы, сертификаты, «Мои проекты».

## Дизайн-система

Оформление берётся из `codify-app-web/design` (соседняя папка в workspace). Чтобы обновить токены после правок там:

```
npm run tokens
```
